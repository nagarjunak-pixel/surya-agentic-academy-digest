# Chroma Awards Season 2 Analytics Dashboard

## PURPOSE
Season 2 of the Chroma Awards returns "with more resources, bigger prizes" and a bigger pool of
creators telling their stories across the competition's theme pillars. Organizers, sponsors, and
the community all want the same thing: a live view of how the season is shaping up. This project
is a Streamlit + Plotly dashboard that turns a raw entries export into interactive charts —
entries per category, distribution across theme pillars, top creator regions, prize-tier
breakdown, and a season-over-season comparison that shows whether Season 2 really is larger than
Season 1.

## WHY THIS MATTERS
A competition generates data every minute it is open, but data stuck in a CSV informs nobody.
Dashboards convert submissions into decisions: where to promote categories that are underfilled,
which pillars need more outreach, and whether prize budgets match the entry mix. Building one
teaches the last mile of any data pipeline — making numbers legible to non-engineers.

## HOW TO BUILD
Streamlit provides the app shell and widgets; Plotly provides the charts. Load the entries with
Pandas, cache it, and hang charts off sidebar filters.

```python
import streamlit as st, plotly.express as px, pandas as pd

@st.cache_data
def load(path): return pd.read_csv(path)

df = load("entries.csv")
theme = st.sidebar.multiselect("Theme pillar", sorted(df["theme"].unique()))
view = df[df["theme"].isin(theme)] if theme else df
st.plotly_chart(px.bar(view.groupby("category").size().reset_index(name="n"),
                       x="category", y="n"))
```

Add a `px.pie` for theme mix, a `px.histogram` for prize tiers, and a season comparison bar.

## WHEN TO USE IN PRODUCTION
Use it for internal analytics, sponsor reporting, and community updates where fast iteration
matters more than millisecond latency. Streamlit is ideal for small teams and demo-day views. Do
**not** use it as a customer-facing public site at scale, for strict-access regulated reporting,
or for real-time streaming data — reach for a compiled frontend plus a query API, or a proper BI
tool, in those cases.

## HOW IT HELPS STUDENTS
Students practice the full analytics loop — load, clean, aggregate, visualize — plus caching and
widget-driven interactivity, a common data-team deliverable.
