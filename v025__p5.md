# AIOS Herk Loop Stack Dashboard

## PURPOSE
A Streamlit + Plotly dashboard that maps a business's AI tool stack onto the "Herk Loop" framework the video promotes: context, connections, capabilities, cadence. It scores each of the seven featured tools against those four pillars, charts monthly cost next to the subscriptions each tool replaces, and flags the weakest pillar so a student can see where their own AI operating system is thin.

## WHY THIS MATTERS
Nateherk says his whole system runs on that loop and that his stack "drives about 90% of my daily workflow" while replacing paid tools like Gamma, Poppy, and Loom. A dashboard makes the abstract framework measurable: which pillar the voice dictation tool (Glido) feeds, which one the image/video API (key.ai) feeds, and where you are paying for capability you never connect. It turns a guru's four-word framework into an instrument.

## HOW TO BUILD
1. `pip install streamlit plotly pandas`.
2. Build a DataFrame of the seven tools with four 0–10 pillar scores, a monthly cost, and a "replaces" column.
3. Render a Plotly grouped bar for pillar scores and a polar line for the stack average.
4. Compute a net-cost column (cost minus replaced spend) to show build-vs-rent payoff.
5. Add a sidebar category filter and a "weakest coverage" callout.

## WHEN TO USE IN PRODUCTION
Use it in an AI-readiness workshop, a client onboarding audit, or a quarterly "where should we invest next" review. Do NOT treat the scores as ground truth — they are subjective by design; and skip it for single-tool setups where a chart adds no decision value.

## HOW IT HELPS STUDENTS
Students learn Plotly Express, Streamlit layout, modeling a qualitative framework as data, and how to translate a thought-leader's framework into something a business can actually act on.
