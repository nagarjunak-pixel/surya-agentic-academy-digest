# Kurnool Youth Engagement & Employment Dashboard

## PURPOSE
A Streamlit + Plotly dashboard that turns the two ideas in this video — the
youth's "great enthusiasm and immense inspiration" at the Dasara Dandiya
celebrations, and the promise of employment support through the Ratan Tata
Innovation Hub — into one page of charts. It lets a district coordinator see
festival participation and the youth placement pipeline side by side, so cultural
energy and economic follow-through are reviewed together.

## WHY THIS MATTERS
The transcript links celebration to inspiration and inspiration to a jobs
assurance. A dashboard makes that chain visible: are the same youth who show up
enthusiastically for celebrations also moving through training into placements?
It teaches the visualization layer that makes a policy promise legible.

## HOW TO BUILD
Use Streamlit for the app shell and Plotly for interactive charts over a Pandas
frame.

```python
import streamlit as st
import plotly.express as px

df = load_metrics()
stage_counts = df["stage"].value_counts().reset_index()
fig = px.funnel(stage_counts, x="count", y="stage",
                title="Youth placement funnel")
st.plotly_chart(fig, use_container_width=True)
```

1. Load (or generate) a metrics frame with festival attendance and pipeline stages.
2. Build a Plotly funnel for enrolled -> training -> placed.
3. Add a bar chart of festival attendance per Kurnool event day.
4. Add KPI tiles (`st.metric`) for total youth reached and placement rate.

## WHEN TO USE IN PRODUCTION
Use it for programme review meetings, public dashboards for skilling schemes, and
anywhere a non-technical audience needs a shareable view of youth outcomes. Do NOT
use Streamlit for high-traffic public sites needing custom UI control or strict
role-based access — pair it with a real backend for that. Avoid it for one-off
static reports where a saved image is enough.

## HOW IT HELPS STUDENTS
Students learn to load real data into Pandas, choose the right chart (funnel vs
bar vs metric), and ship an interactive dashboard in under a hundred lines — a
directly employable analytics skill.

## STARTER CODE
`starter/main.py` renders KPI metrics, a Plotly placement funnel, and a festival
attendance bar chart from deterministic sample data, with `# TODO` markers for
loading a live CSV or database source.
