# Ratan Tata Innovation Hub Youth Upskilling CLI

## PURPOSE
A Click + Pandas command-line tool that tracks the youth employment pipeline the
Minister promised in this video: enrolment, skill training, and placement of
Kurnool's local youth through the Ratan Tata Innovation Hub. It ingests a simple
CSV roster and produces per-batch reports so a coordinator can answer "how many
trainees are placed this month?" without opening a spreadsheet by hand.

## WHY THIS MATTERS
The transcript records a "strong assurance that in the coming days, local youth
would be fully supported with employment opportunities through the Ratan Tata
Innovation Hub." An assurance becomes measurable only when the pipeline is
tracked. This project teaches the data tooling that turns a public promise into a
countable, reportable programme.

## HOW TO BUILD
Use Click for the CLI surface and Pandas for the aggregation.

```python
import click
import pandas as pd

@click.group()
def cli():
    """Youth upskilling pipeline tools."""

@cli.command()
@click.option("--csv", "csv_path", required=True, type=click.Path(exists=True))
def summary(csv_path):
    df = pd.read_csv(csv_path)
    placed = (df["stage"] == "placed").sum()
    click.echo(f"trainees={len(df)} placed={placed}")
```

1. Define a roster schema: `trainee_id, name, batch, stage, skill, placed_on`.
2. Add `summary` (stage counts) and `batch --name` (per-batch funnel) commands.
3. Add `export --out report.csv` writing the aggregated funnel.
4. Validate stages against an allowed set and fail loudly on bad rows.

## WHEN TO USE IN PRODUCTION
Use it for skilling programmes, government placement drives, NGO training cohorts,
and any recurring CSV-to-report job run from cron or CI. Do NOT use it for live
multi-user editing — that needs a database and API (see p4). Avoid it when the
data is already modelled in a warehouse with BI tooling.

## HOW IT HELPS STUDENTS
Students learn Click command design, typed options, real Pandas groupby/pivot
aggregation, and how to ship a report generator that a non-technical coordinator
can actually run.

## STARTER CODE
`starter/main.py` provides a Click group with `summary`, `batch`, and `export`
commands, a deterministic sample roster fallback, and `# TODO` markers for schema
validation and richer funnel metrics.
